# q36 f=2 far-target-K2 — A3 repeated-K3 single-disjoint-class reduction

Status: `RETRACTED`.

This file previously claimed that the Type-P / Type-Q terminal from `Q36_F2_FAR_K2_C8_D2_A3_REPEATED_K3_CORRECT_REDUCTION.md` collapses to one single disjoint support class.

The proof used an invalid assumption: it treated a target K4 as forbidden. That is not part of the current backend/T61 contract. The working residual explicitly allows target cliques up to size 11; inherited D14 arguments are built on target K11s. Therefore neither

- the exclusion of the Type-Q four-set family by a target K4, nor
- the deduction that two Type-P petals must be target-nonadjacent

is justified.

Consequently the claimed single-class collapse is withdrawn.

The last valid state is the preceding file:

`Q36_F2_FAR_K2_C8_D2_A3_REPEATED_K3_CORRECT_REDUCTION.md`

which proves only that distinct disjoint-from-D K3 support classes form a 3-uniform pairwise-2-intersecting family of Type P (common pair) or Type Q (four-set), subject to the D14 multiplicity interface.

No stronger realization claim is certified here.
