# Strengthening R(4,48): exclusion of the 309-edge equality layer

Status: `PROVED`, conditional only on the already canonical q20 shell classification recorded in `front_end/T61_NEW_LEMMAS.md`.

## Theorem

Every `C in R(4,48)` satisfies

`e(C) >= 310`.

Equivalently, the previously surviving 309-edge equality layer is empty.

## Proof

Assume `e(C)=309`. The canonical 48-point argument gives a degree-12 pivot `p`, a 12-shell `A`, and a 35-core `H` with

`309 = 78 + q + e(H)`.

The shell floor gives `q>=20`, and CORE211 gives `e(H)>=211`, so necessarily

`q=20`, `e(H)=211`.

The canonical q20 equality classification gives

`M = K_{2,r} disjoint_union (10-r)K1`, `6<=r<=10`,

for the shell missing graph `M`. Let `a,b` be the two centres. Each leaf `y` is undecorated, has missing degree2, and has a 2-vertex core row

`P_y={u,w}`.

For each centre-leaf missing edge, the equality classification gives

`P_y intersect D_a = P_y intersect D_b = empty`,

where `D_a,D_b` are the two 10-vertex centre rows.

Because `y` is an undecorated degree-2 leaf in the missing graph, its actual degree in `C` is exactly12. Repivot at `y`.

The new shell consists of

`{p} union T union {u,w}`,

where `T` consists of the nine old shell vertices target-adjacent to `y`.

In the new missing graph:

- every vertex of `{p} union T` has missing degree at most2;
- only `u,w` can therefore be the two high-degree centres required by the q20 classification (the centres there have degree at least6).

Hence `u,w` must be the two new centres. In particular they are nonadjacent in the new missing graph, so `uw` is a target edge in the old core `H`.

Now inspect the new core row of `u`. The new core is

`H_y=(H minus {u,w}) union {a,b}`.

Since `P_y` is disjoint from both centre rows, `u` is target-nonadjacent to both `a,b`. Since `uw` is a target edge in `H`, the number of target neighbours of `u` in the new core is

`d_H(u)-1 >= 11`,

because `delta(H)>=12`.

But in every q20 shell normal form, each centre has core-row size exactly10. Contradiction.

Therefore no 309-edge member of `R(4,48)` exists, proving

`e(C)>=310`.
