Status: source/provenance map only. No result in this file is canonical unless separately promoted.

## I version

I223-296 contains the strongest recovered q=29 material among A-I.

Recovered structure:
- q=28 branch: 208/209/210 core-edge rows are eliminated under the specific q28 shell/core contract; this is not the universal CORE211 theorem.
- q=29 triangle-free branch: matching/cover argument forces a bipartite K_{3,10}-subgraph structure, then an exact 10-row dynamic program eliminates the triangle-free branch.
- q=29, triangle but no K4: outside graph is reduced to empty or a star; exact scalar/attachment analysis eliminates this non-K4 branch using the r=12 heavy-four theorem.
- q=29 K4 branch: reduced to six attachment-terminal states after a 3297-vs-3630 row-cover deficit calculation, but the final r=11 -> r=12 row-cover certificate was not reconstructed inside the I-version proof body.

Therefore I recovers most of the generic q29 proof body but not a fully standalone closure.

I149-222 also contains r=12 strict-triple / strict-clique upper inequalities and triangle-free component-penalty calculations. These are potentially reusable weighted-shell tools, but several steps are explicitly migrated from r=11 and must be audited before canonical use.

## J version

J1-51 revisits the older full-color bootstrap route. It corrects an earlier Kang-Pikhurko numerical mistake, but its F12(4,49)=empty conclusion remains conditional on a previously validated public-recursion lower bound B12(4,49)>=309. This is not accepted as a modern canonical proof of the 49-vertex emptiness statement.

Later J sections develop a different Gallai-critical / attachment-hypergraph / witness-capacity program. They are historically valuable structural tools but do not presently replace the modern T61 + R(4,49) architecture.
