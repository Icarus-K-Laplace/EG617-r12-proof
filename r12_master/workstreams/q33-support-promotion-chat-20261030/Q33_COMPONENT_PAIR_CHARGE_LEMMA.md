# Scope correction — fixed four-core component-pair charge

The inequality
\[
\binom{4-k}{2}+2\binom{k}{2}\ge3
\]
is valid for a component with exactly four core vertices. Summing it over 3m+h remaining components assumes every unselected K5 has exactly four core vertices.

The source-verified exact-129 factorization alone permits a component to contain multiple shell vertices, so its core size can be c<4. The universal component contribution is instead
\[
\binom{c-k}{2}+2\binom{k}{2},
\]
whose minimum can be0,1,2, or3 depending on c. Therefore the earlier 3m+h aggregate charge is retained only as a conditional special case under the one-shell-per-component premise. The variable-core profile theorem supersedes it for the source-correct screen.
