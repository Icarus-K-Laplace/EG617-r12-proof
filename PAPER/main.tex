\begin{abstract}
A balanced $r$-edge-coloring of a complete graph is an edge-coloring in which every set of $r+1$ vertices spans an edge of every color. Erd\H{o}s and Gy\'arf\'as conjectured that, for every $r\geq 3$, the complete graph $K_{r^2+1}$ has no balanced $r$-edge-coloring. We prove the fixed case $r=12$: no edge-coloring of $K_{145}$ with twelve colors has the property that every thirteen-vertex set contains all twelve colors. The proof chooses a color class of minimum size and derives hereditary induced-subgraph edge caps. A contextual Ramsey--Tur\'an argument and an exact finite recurrence reduce a hypothetical counterexample to a sixty-one-vertex residual graph with between $397$ and $408$ edges. The terminal analysis combines a forty-seven-vertex low-edge obstruction, a separate forty-eight-vertex floor, and a repivot/charge theorem for the minimum-degree-thirteen case. The argument is an informal mathematical proof supported by finite computational verification and an independent AI-assisted audit of a pinned proof snapshot. It is not proof-assistant formalized and has not yet undergone external human peer review.
\end{abstract}
